## Checked and sound (reviewer)

- Vote ordering under deferred execution: a vote leaves only on `BlockChecked` or `BlockImported` (state_machine.rs:1158 -> proposal.rs:626-651); `BlockChecked` only from `release_check`, which needs `Valid` (driver.rs:932-947); the check-ahead path proves the header hash before asking (driver.rs:2046-2056); `check_only_over_channel` needs a CHECKED frame for that hash (engine.rs:2236-2242); a failed import withdraws the evidence (service.rs:4041-4050 -> proposal.rs:614); a block dropped while held cannot release a vote (driver.rs:2577); `extends_justify` applies to checked blocks too (service.rs:3937-3941).
- The leader's own block is marked imported before its import (service.rs:3724) by design: the header carries the parent's execution.
- Progress votes are signed over a different message, not recorded as votes, sent only to the passed view's leader (proposal.rs:654-675).
- Settlement: `safe`/`finalized` only move forward; `finalized = min(safe, persisted)` by number with the hash from safe's lineage (settlement.rs:249-291); a tag off the head's chain is sent as zero (297-308); an unknown or failed persisted reading holds `finalized` (271); pulled blocks never move either tag (driver.rs:2742-2747); `finalized` moves only on `Valid` (3085); lineage keys are header-derived (2674-2675, 2658).
- Commit FCU: failures retried with backoff off the loop (3114-3171); `Invalid` halts voting and proposing (service.rs:1570-1590), checked after each driver action (3082, 2995).
- 6.9 QC embedding: the QC comes only from the engine's commit-domain `last_committed_qc`; view 0 embeds nothing; pinned per `(number, view)` (service.rs:868-905, 1668-1691); `check_pulled_block` refuses a QC view above the header's and a certified block at or above the header's height.
- Body channel: declared length capped, allocation grows with data (body_channel.rs:319-378), connection semaphore (242-256), per-frame deadline.
- Peer input: range reads stop at 128 MB + one chunk (rpc.rs:956-983); snappy allocation bounded by `max_wire` (rpc.rs:56-96); gossip decompression checks the declared length (block_gossip.rs:145-154); `inbound_transactions` capped (service.rs:2350); range/by-hash/txns serving on the non-elided path off the loop and slot-capped (2633-2645, 2746-2757, 2426-2430).
- Persisted-height poller: a failed poll reads `Unknown`, never stale (in_memory.rs:116-132).
