## Checked and sound (reviewer)

- Profile: an operator-set value (incl. `=0` and empty) is never overridden; an unknown profile exits 2; `x22_is_exactly_the_adopted_rows_of_knobs_md` binds X22 to the `adopted` rows; no `bench-only`/`unsafe-bench` knob is in X22 (spot-checked `HASHED_TABLES`, `ACCOUNT_HISTORY`, `IMPORT_ONCE`, `INGEST_VERIFY`, `VOTE_LOG_NOSYNC`, `ROCKSDB_NOSYNC`, `VOTE_BEFORE_IMPORT`, `FRAME_GATEWAYS`) -- the problem is status, not the test (E-1).
- Withdrawal and chain gating: `reconcile` removes only profile-set knobs whose requirement the chain lacks; `remaining` checked by test; both binaries reconcile before any frame knob is read; an operator's `N42_FRAME_BLOCKS=1` is left for `frame_blocks::init` to refuse.
- `MERGE_ELIDE` refused on a production storage mode.
- New hardening on main holds: `recover_poisoned`; thread-spawn fallbacks; build-pool halving; `HoldGuard`/`HELD_RELEASE_TIMEOUT`; `payload_serve` bounds (frame len/count, 64-connection semaphore, 30 s body deadline, accept back-off, loopback refusal); `submitVerification` error path; pruner panic catch, inline fallback, `FEED_DEPTH` reset; QMDB follower on its own thread with a fatal exit; persistence defaults; BMT depth bound; `n42_evm` seal-recover warning. No new `unwrap`/`expect` on block paths.
- offsets.rs: directory pointer stored with release before the length; never reallocated; segments freed only in `Inner::drop`; transmute size/alignment asserted; `Clone` deep copy publishing the length last; `truncate` keeps segments.
- Stage 2: root neutrality checked before any write; active bits untouched; open checks CRC, trailer twig id, slot sequence, drops twigs past kept slots; group synced before any retarget; `truncate` refuses to cut into a relocated twig; undo clamp plus `last_retired_at` prevents reviving a compacted slot on reorg; duplicate is read-only; `create` removes a stale relocated file; portable export refuses; checkpoint v1/v2 serde round-trips.

## Not covered (reviewer)

Areas A-D; exact delta-log/checkpoint durability (E-3 relies on "durable at persistence");

pruner panic; runtime behaviour, Linux tests, and the cost of atomic stores replacing `memcpy` in
`extend_from_slice` (flagged by e6b7b3701 itself). Nothing built or run.
