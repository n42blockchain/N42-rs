## Rules the Rust fixes must keep

- Accept headers with no QC; never require or verify a header seal.
- Verify a header QC in either domain, but canonicalize only from a commit-domain QC; signer sets resolved by view.
- Keep the ParentBeaconRoot committee-evidence link and `qc.View <= headerView`.
- Extends rule stays parent == justify block (zero justify allowed); abstaining when unsure is local and safe.
- Per-view double-sign protection; a leader treats a repeated vote as a no-op (gov5 resends on repeated timeouts).
- Votes reach the leader and also the gossip mesh; HighTC stays on votes, commit votes and timeouts.
- Catch-up height is the committed height; forks recover by an authorised branch switch from it, backtracking up to 32 blocks.
- A block is bad only on deterministic execution failure.
